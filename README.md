# Foundation 🏗️

Это универсальный дом агента. Внутри — устав, память, знания и механизм подключения способностей, общие для любой специализации, которая будет собрана поверх.

Ты разворачиваешь этот дом один раз, а специализацию (роль, характер, набор скиллов) подключаешь поверх него отдельно.

**Foundation сознательно не содержит профессию.** Внутри нет ни одного скилла, который умеет что-то конкретное — писать код, искать источники, вести соцсети. Это дом, а не жилец: профессию приносит специализация, которую ставят поверх уже после установки. Подробнее — в `VISION.md`.

---

## Идея Foundation

Foundation — не готовый агент. Это фундамент, одинаковый для любого будущего агента.

Дом отвечает только за универсальные механизмы:

- память;
- правила работы;
- маршрутизацию;
- обновление;
- хранение знаний;
- подключение способностей.

Любая специализация (Research, Engineer, Strategist, Writer и т.д.) строится поверх Foundation и не изменяет сам фундамент. Foundation развивается отдельно от специализаций.

---

## Что где лежит

Весь репозиторий — это Дом: разворачивается целиком, один раз. Новые способности не входят в исходный клон — они докупаются по одной уже после установки, через скилл `installer`, с отдельного, внешнего склада.

### Внутри дома

| Папка / файл | Что это |
|---|---|
| `VISION.md` | Зачем Foundation существует — прочитать первым, до устава |
| `HOME.md` | Устав — кто агент и как работает |
| `AGENTS.md` | Тонкая надстройка для сред, ищущих именно этот файл |
| `SOUL.md` | Характер — точка расширения, заполняется специализацией |
| `PROFILE.md` | Профиль владельца — точка расширения, заполняется по ходу знакомства |
| `MEMORY.md` | Постоянная память — что верно всегда |
| `memory/` | Дневник по дням + правки |
| `knowledge/` | Копилка знаний по темам |
| `instructions/` | Правила работы памяти и маршрутизации |
| `skills/` | Установленные способности (склад — внешний, отдельный адрес) |
| `workspace/` | Готовые результаты работы |
| `ROUTING.md` | Что читать под какую задачу |
| `UPDATE.md` | Правила безопасного обновления |
| `COMMUNICATION.md` | Правила взаимодействия, если агентов больше одного |

## Как поставить дом

```bash
git clone --depth 1 https://github.com/megapolisagent/FOUNDATION.git .
rm -rf .git
```

`skills/` в этом репозитории — не внешний склад, а рабочая папка уже установленных способностей (на старте — только `installer`). Склад, откуда `installer` берёт новые скиллы, — отдельный, внешний адрес, никак не зависящий от структуры самого Foundation.

После клонирования напиши агенту `привет` — он представится и покажет, что дальше.

## Как докупать способности

Когда нужна новая способность — попроси агента словами: «поставь скилл X». Установщик возьмёт нужный скилл со склада, включит и объяснит, как проверить.
