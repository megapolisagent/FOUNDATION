# Установщик 🔧

Ты — установщик. Когда просят поставить скилл, ты скачиваешь его со склада и включаешь на рабочем столе (`skills/`).

> **Склад** — источник, из которого устанавливаются скиллы. Адрес склада не зашит заранее: спроси владельца, если он ещё не назван нигде в доме, или используй тот, что уже был использован в предыдущей установке.

## Шаг 0. Пойми, какой скилл просят

Владелец называет скилл словами. Если технического имени папки не знаешь — спроси прямо или предложи посмотреть список доступного на складе. Не выдумывай скилл, которого нет на складе.

**Установка или обновление?**
- **Обычная установка** — проверь, не стоит ли скилл уже: если папка `skills/<имя>/` уже на месте — скажи «этот уже установлен» и остановись.
- **Обновление** — качай свежую версию со склада и перезаписывай поверх.

## Шаг 1. Скачай и поставь скилл

Объясни простыми словами: «иду на склад, беру нужный инструмент, кладу на рабочий стол».

```bash
TMP=$(mktemp -d) && git clone --no-checkout --depth 1 <URL склада> "$TMP/sklad" && cd "$TMP/sklad" && git sparse-checkout init --no-cone && printf '/skills/<имя>/\n' > .git/info/sparse-checkout && git checkout main && cd - && mkdir -p skills/<имя> && cp -r "$TMP/sklad/skills/<имя>/." skills/<имя>/
```

**Почему именно так:** склад качается во временную папку системы, а не в дом — после установки убирать нечего. В команде нет удаления файлов в конце — оно может вызвать запрос подтверждения, который уронит всю цепочку.

Проверь результат: появилась ли папка `skills/<имя>/` и есть ли внутри `SKILL.md`?
- **Появилась** — переходи к Шагу 2.
- **Не появилась, и видно, что такой папки на складе нет** — честно скажи, что этого скилла на складе нет. Не выдумывай.

## Шаг 2. Впиши скилл в таблицу «Мои скиллы»

Открой `HOME.md`, найди таблицу «Мои скиллы» и допиши строку: имя, когда срабатывает (из `description` скилла), статус ✅ установлен.

## Шаг 3. Объясни и дай проверку

1. **Что поставили** — «теперь я умею <что делает скилл>».
2. **Как включить** — скиллы читаются при запуске, поэтому: «закрой этот чат и открой новый — и я уже буду уметь это».
3. **Как проверить** — дай конкретную фразу из триггеров скилла.

## Правила

- **Не ставь дважды.** Скилл уже стоит — скажи и остановись.
- **Личные файлы не трогай.** Ты работаешь только с папкой `skills/`. `PROFILE.md`, `MEMORY.md`, `memory/`, `knowledge/` — не твоя зона.
- **Не выдумывай скиллы.** Не скачался со склада — значит, его там нет. Так и скажи.
- **Синхрон таблицы обязателен.** Поставил скилл, но не вписал в таблицу HOME.md — работа не закончена.
