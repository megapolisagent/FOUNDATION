# Взаимодействие

Foundation первой версии — одноагентный дом. Этот файл не описывает работающий механизм, а фиксирует разграничение, которое понадобится, когда (и если) в доме появится больше одного агента — чтобы не смешать два разных вопроса при проектировании.

## Два разных протокола, не один

- **Агент ↔ инструмент** — уже покрыто механизмом `skills/`: агент вызывает способность, способность выполняется, результат возвращается. Это уже работает.
- **Агент ↔ другой агент** — не покрыто ничем в текущей версии. Это другой вопрос: как один агент передаёт задачу или контекст другому, потенциально независимому агенту, не имея доступа к его внутреннему состоянию.

Смешивать эти два протокола в одном механизме — источник путаницы: правило, разумное для вызова инструмента (агент полностью управляет вызовом), не обязательно разумно для передачи задачи другому агенту (нужна договорённость о том, кто владеет финальным ответом).

## Когда этот файл понадобится

Когда специализация введёт больше одного агента (субагенты, параллельные инстансы, внешние агенты) — здесь фиксируются правила: кто владеет финальным ответом при передаче задачи, как агенты обнаруживают возможности друг друга, как оформлена единица работы (передана целиком или по частям).

До этого момента — файл существует как явное напоминание не решать эту задачу попутно, обходным путём через `skills/`.
